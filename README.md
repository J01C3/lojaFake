# 🛍️ Loja Fake - Ionic Angular

Um aplicativo mobile desenvolvido com **Ionic + Angular Standalone** + TypeScript, consumindo uma API de produtos e exibindo os itens em uma interface moderna e responsiva.

---

## 📱 Preview

✨ Interface moderna  
✨ Cards de produtos  
✨ Integração com API  
✨ Navegação por Tabs  
✨ Compatível com Android APK  

---

## 🚀 Tecnologias utilizadas

- Ionic Framework
- Angular Standalone
- TypeScript
- SCSS
- Capacitor
- Fake Store API

# 📂 1. Clonar o repositório

Abra o terminal na pasta que você quiser.

Depois rode:

```bash
git clone https://github.com/J01C3/lojaFake.git
```

---

# 📁 2. Entrar na pasta do projeto

```bash
cd lojaFake
```

---

# 📦 3. Instalar dependências

```bash
npm install
```

Isso pode demorar alguns minutos.

---

# ▶️ 4. Rodar no navegador

```bash
ionic serve
```

Depois disso o navegador abrirá automaticamente.

# 📱 Rodar no Android Studio

## 1. Adicionar Android

```bash
ionic capacitor add android
```

---

## 2. Gerar build

```bash
ionic build
```

---

## 3. Sincronizar projeto Android

```bash
npx cap sync android
```

---

## 4. Abrir Android Studio

```bash
npx cap open android
```
